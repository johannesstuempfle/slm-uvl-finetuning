# FA-3908Schatz

For usage:
1. Clone Repo
   ```
   git clone *link*
   ```
2. Create/Start vitual environment by selecting uv folder and start virtual environment
   ```
   $ cd FA3908
   $ uv venv
   ```
4. Sync/Download all dependencies
   ```
   $ uv sync
   ```
5. Run script by
   a. Selecting .venv interpreter as Interpreter in IDE and run file
   b. Run via terminal:
     ```
     $ ./FA3908/.venv/bin/python3.12
     ```
